# HR Analytics Dashboard (Excel)

An interactive Excel dashboard and insights deck that analyse employee attrition for **1,470 employees**.

## Overview
The dashboard shows who is leaving, where, and why. Every number and chart is a live formula driven by the raw HR data, so it updates when the filters change.

## Key Metrics
| Metric | Value |
|---|---|
| Employee Count | 1,470 |
| Attrition Count | 237 |
| Attrition Rate | 16.12% |
| Active Employees | 1,233 |
| Average Age | 37 |

## Dashboard Features
- KPI tiles: employee count, attrition count, attrition rate, active employees, average age
- Attrition by gender
- Department-wise attrition (pie chart)
- Employee count by age group, with an adjustable **Bin Size**
- Job satisfaction heatmap by job role
- Education field-wise attrition
- Attrition by gender across five age groups (doughnut charts)
- **Education Field** dropdown that filters every number and chart

## Key Insights
- **Overtime:** 30.5% of overtime staff left, against 10.4% of the rest.
- **Age:** under-25s have a 39.2% attrition rate, and the 25-34 group holds 47% of all leavers.
- **Role:** Sales Representatives have the highest attrition at 39.8%.
- **Department:** Sales has the highest rate (20.6%), while R&D has the most leavers (133).
- **Pay:** leavers earn about $4,787 a month, against $6,833 for stayers.
- **Travel:** frequent travellers leave at 24.9%, against 8.0% for non-travellers.

## How to Use
1. Open `HR_Analytics_Dashboard.xlsx` and go to the **Dashboard** sheet.
2. Pick a field in the **Education Field** dropdown to filter the dashboard.
3. Change **Bin Size** (3 to 10) to regroup the age chart.
